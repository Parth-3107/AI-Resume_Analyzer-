# AI Resume Analyzer

An intelligent resume analysis tool that extracts skills and calculates ATS (Applicant Tracking System) compatibility scores by comparing resumes against job descriptions.

## Features
-  PDF Resume Upload & Text Extraction
-  Automatic Skill/Keyword Extraction using NLP
-  ATS Score Generation with TF-IDF & Cosine Similarity
-  Real-time Match Analysis & Recommendations

## Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python 3.9+
- **NLP:** spaCy
- **Machine Learning:** scikit-learn
- **PDF Processing:** PyPDF2

### Prerequisites
- Python 3.8 or higher
- pip package manager
